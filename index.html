C. Aktivitas 1: Eksperimen "10" + "20"

Kode yang diuji:

let a = "10";
let b = "20";
console.log(a + b);

Output Program: 1020 (Penggabungan teks / konkatenasi, bukan penjumlahan angka).

Penjelasan: Variabel a dan b bertipe String karena diapit tanda petik, jadi operator + berfungsi untuk menggabungkan string.

E. Aktivitas 3: Konversi String Menjadi Number

Memperbaiki program agar menghasilkan 30 menggunakan Number()[cite: 2]:

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil); // Hasil: 30
